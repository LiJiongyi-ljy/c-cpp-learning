一、这份清单的用途
------------------
本清单将“总学习大纲”与当前学习记录逐项对照，区分：
1. 已有记录明确表明掌握的内容；
2. 已接触，但还需要在真实程序中巩固的内容；
3. 大纲中有、但学习记录没有证明已经系统学过的内容；
4. 属于后续阶段的内容，目前尚未学到是正常的，不应误当成当前落后的欠账。

重要原则：
- “没有记录”不等于“肯定不会”。对无法确认的知识，先用小问题检查；如果已经掌握，只标记完成，不重复上课。
- 这是一份查漏清单，不要求一次全部补完。
- 当前学习已经进入较进阶的指针/动态内存/函数接口内容。无需抹掉已有进度；可以先完成当前函数接口主题，再按本清单逐步补齐早期知识缺口。

状态标记：
[已掌握/有记录]：现有学习记录明确表示已理解或掌握。
[已接触/需巩固]：已经讲过，但需要做练习或放进完整程序中验证。
[优先确认]：学习记录未充分说明是否系统学习，优先用小测检查。
[尚未系统学习]：目前记录显示还没有完整学习该模块。
[后续进阶]：不影响当前基础路线，可在合适阶段学习。

二、已经学过、不应重复从头讲的内容
----------------------------------
以下内容在当前进度记录中已有明确记录。后续可通过综合题巩固，但不应重新从定义开始讲：

[已掌握/有记录]
- 编译运行基本流程：预处理、编译、汇编、链接、运行；GCC 基本编译命令。
- Hello World、main、printf、\n、return 0/1 与程序退出状态的基本概念。
- void 的基本用法，以及基础变量、声明、赋值和初始化的直觉。
- 基础类型 int、float、double、char；字符与字符串字面量的基本区别。
- printf 的 %d、%f、%c 基础用法。
- 内存、地址、&、指针变量、解引用 *。
- 指针类型、sizeof、size_t 与 %zu 的基本用法；指针大小和所指类型大小的区别。
- 指针运算、数组基础、数组下标与指针运算的关系、sizeof 数组与 sizeof 指针的区别。
- 数组越界、off-by-one、undefined behavior（未定义行为）的基本意识。
- NULL 指针、未初始化指针、悬空指针、use-after-free、double free、memory leak 的基础概念。
- malloc、calloc、realloc、free 的核心用途；分配失败检查；realloc 使用临时指针的安全思路。
- void * 与 typed pointer 的基础关系，以及通常不需要对 malloc 返回值进行强制类型转换。
- 多指针别名、ownership（所有权）与释放责任的初步意识。
- int **、pp → p → x、多层解引用，以及通过 int ** 访问调用者指针变量。
- 函数输出参数的初步概念：int *out 写入普通结果，int **out 可用于把新分配的指针交给调用者。

[已接触/需巩固]
- 函数中的值传递（pass by value），包括指针参数也按值传递。
- 通过函数参数修改调用者对象，与修改调用者指针变量之间的区别。
- 函数返回状态码、输出参数、malloc 失败检查、free 与所有权责任的组合。
- 以上动态内存与函数接口知识还需要通过小型完整程序巩固，特别是失败路径和资源清理。

三、优先查缺补漏：早期知识中“没有明确学完记录”的内容
------------------------------------------------------
这些主题在完整大纲中属于基础主线，或是后续学习的重要前置知识。按优先级列出，但先检查再补学。

P1. 运算符与表达式（大纲 C）[优先确认]
学习记录没有明确证明已系统学习以下内容：
- [ ] 算术运算符：+、-、*、/、%；尤其是整数除法与取模。
- [ ] 比较运算符：==、!=、<、<=、>、>=。
- [ ] 逻辑运算符：&&、||、!，以及短路求值的基本效果。
- [ ] 赋值与复合赋值：=、+=、-=、*= 等。
- [ ] ++、-- 的前置/后置形式，以及什么时候应避免把复杂的自增表达式写在一起。
- [ ] 条件运算符 ?:。
- [ ] 运算符优先级与结合性；知道优先级不等于表达式一定按该顺序求值。
- [ ] 隐式类型转换、显式强制转换，以及 int 与 double 混合运算的结果。
- [ ] 有符号与无符号整数、短整数/长整数类型、常见整数范围。
- [ ] 浮点数精度：为什么某些十进制小数不能被二进制浮点数精确表示。
- [ ] 求值顺序、副作用，以及避免在一个表达式中不当修改/读取同一对象。
- [ ] 未定义行为、未指定行为、实现定义行为的区别；有符号溢出和整数除零等常见风险。
- [ ] limits.h、float.h、stdint.h 的用途（可随相关章节逐步学习）。

建议做法：先确认基本运算和类型转换，再把求值顺序、实现差异和高级边界情况放到后续巩固，不必一次讲完。

- [ ] while、do while、for 三类循环。
- [ ] break 与 continue 的区别。
- [ ] 嵌套条件与嵌套循环。

这是很重要的基础缺口候选。若这些语法你已经会，做一道小练习确认即可，不必重新学习整章。

- [ ] 学到字符串后使用 fgets 读取一行、处理换行符，并检查读取结果。

提醒：可靠的文本输入依赖字符串与缓冲区知识，适合先学基本数值输入，再在字符串模块中系统学习 fgets 与文本解析。

六、最建议的补漏顺序
--------------------
为了既不浪费已学进度，又逐渐恢复完整主线，建议按以下顺序进行。每项先小测，已掌握就快速通过；没掌握再讲解。

第 1 步：完成当前正在学习的函数接口主题
- [ ] 函数返回值与输出参数如何选择。
- [ ] 成功/失败状态码与输出参数如何配合。
- [ ] 失败时输出参数应保持什么状态。
- [ ] malloc 产生的资源由谁释放；函数何时转移所有权。
- [ ] 分配失败、参数无效、清理路径与调用者契约。

第 2 步：快速检查早期基础是否存在缺口
- [ ] 运算符与表达式。
- [ ] if/switch/循环及边界跟踪。
- [ ] scanf 和输入检查的基础。
- [ ] 函数原型、作用域、生命周期、递归的基础。
- [ ] 数组作为函数参数与长度单独传递。
- [ ] signed/unsigned、转换、const、类型范围。
- [ ] GCC 警告选项与 GDB 基本操作。

第 3 步：完整学习字符串与可靠输入
- [ ] '\0'、字符串遍历、容量、标准字符串函数、snprintf、fgets。
- [ ] 字符串输入验证和异常输入处理。

第 4 步：学习结构体并进行第一次综合练习
- [ ] struct、enum、typedef、结构体数组。
- [ ] 用结构体保存一组记录；使用函数完成查询、添加和修改。

第 5 步：文件操作与资源管理
- [ ] 文本文件读写、错误处理、关闭文件。
- [ ] 把结构体记录保存到文件并重新读取。

第 6 步：预处理器、多源文件和模块化
- [ ] .h/.c、函数原型、extern/static、链接。
- [ ] 将小项目拆分为多个模块。

第 7 步：进阶语言规则与算法/项目
- [ ] 求值顺序、整数提升/常见转换陷阱、未定义行为类别。
- [ ] 位运算、函数指针、动态数组、链表等按顺序继续。
- [ ] 每个项目均包含输入检查、失败路径、资源释放和基本测试。

七、下一节的建议与短期学习计划
------------------------------
当前学习位置仍然是：函数接口设计（大纲 E）与动态内存（大纲 I）的交叉处。

下一节不要直接跳到结构体或文件操作，而是先完成：
1. 对比“函数直接返回 int *”和“用 int **out 输出地址、用返回值报告成功/失败”。
2. 定义分配成功/失败时输出参数的状态，避免调用者拿到未定义或过期的指针。
3. 明确 ownership：谁负责 free、何时转移责任，以及函数失败时如何清理。
4. 用一个短小的、可编译的 C17 示例组合这些知识。

完成这一单元后，安排一次“早期基础查缺小测”，重点覆盖运算符、流程控制、输入、函数基础、数组参数和类型转换。小测结果决定哪些主题需要补课，哪些可以直接标记掌握。

- 对当前没有记录的项目，不直接判定用户不会；先检查再标记。
- 新发现的重要遗漏，补进总大纲与清单，并标明核心或进阶。
- 每次只推进一个明确的小单元，不一次把清单所有内容塞进课程。
