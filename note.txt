编译器compiler
编译器把整个源代码文件从头到尾完整扫描，一次性翻译成机器码或目标代码，然后生成一个独立的可执行文件。之后运行时，计算机直接执行这个可执行文件，不再需要编译器参与。
C就是典型的编译型语言

解释器interpreter
解释器不生成独立的可执行文件。它从头到尾逐行读取源代码，翻译一行、执行一行。程序运行过程中，解释器始终在场。
Python就是典型的解释型语言

Pointer Arithmetic

int *p;
p + 1  则对应位置为1000 + 4
p         → 1000
p + 1   → 1004
p + 2   → 1008
p + 3   → 1012
指针类型不仅影响 *p 如何访问对象，也影响指针运算如何移动
指针运算会按照它所指向的类型的大小进行缩放（scaling）
Pointer arithmetic is scaled by the size of the pointed-to type
char *q;
q + 1 则对应位置为1000 + 1

define function

```c
void change(int x)
{
    x = 100;
}
int main(void)
{
    int age = 20;
    change(age);
    printf("%d\n", age);
    return 0;
}
```
普通参数：void change(int x) 传进去的是”值“（pass by value）
所以函数修改：x = 100;
不会修改 main 里的原变量

重要：
int *create_number(void);
定义函数时加上 * 表示输出结果为指针

array in function

An array is not a pointer, but in many expressions, an array name is converted to a pointer to its first element.

C uses pass by value, but when an array is passed to a function, the value passed is typically the address of its first element.

why is here two "*" ? Because ** means pp has to dereference twice to reach the original value(the int)

输出参数就是：调用者把一个可以写入结果的位置交给函数，让函数把计算结果写回去。
An output parameter allows a function to send a result back to the caller through a parameter.

=================================================

函数接口（function interface）：调用者如何使用函数，以及函数会返回什么。
接口契约（interface contract）：函数对输入、返回值、失败行为和资源责任所作的约定。

状态码（status code） 是用于表示执行结果的值；枚举（enumeration，enum） 可以给一组相关的整数状态起上有意义的名字。
